Production counts (for the rejection rate)

Upload parts produced per machine, production day and shift as a CSV file with the columns shop,machine,date,shift,produced (date as YYYY-MM-DD, shift A/B/C). Existing values for the same machine, day and shift are replaced. The whole file is checked first; nothing is saved if any row is wrong.

Counts of rejected parts recorded in the app; reversed entries (approved corrections) are excluded. Production days start at the first shift; night-shift entries after midnight belong to the previous day. The rejection rate uses only rejected parts of machines, days and shifts that have a production count, as shown by its coverage.
